# 遊戲設計文件：食農新日常——從產地到餐桌的農業經濟民主之路

## 目標與受眾

給**完全不了解合作社**的一般民眾玩的線上小遊戲，透過角色扮演與抉擇，體會「生產者 + 消費者」共同組成團結經濟合作社的過程：怎麼找到第一批夥伴、為什麼要合作、合作社如何運作、治理民主怎麼落實、合作社通常怎麼失敗。

內容改編自兩份文獻：簡報《從產地到餐桌：如何經濟民主》與論文《合作的艱難：勞動合作社的比較利益－以勞動者觀點出發》（皆為洪敬舒），所有情境與案例皆為**改寫詮釋**，非逐字引用；合作社小百科的每一則條目也都在遊戲內個別標註對應的資料來源。

## 核心玩法

單人、回合制的文字抉擇模擬遊戲（decision-based sim）。玩家扮演「光農合作社」的發起人之一，在四個發展階段中，面對一系列取材自文獻概念的情境事件，每個事件有**四個選項**（增加彼此的鑑別度，避免落入單純的「好/中/壞」三選一），做出選擇。**選項本身不會預先顯示指標增減**——結果只在按下之後才揭曉，避免玩家為了衝數值而選擇，而是真的憑情境判斷做決定；選完之後，指標區會用浮動徽章＋脈動效果呈現這次造成的變化。每個階段的事件池有 5 則，每局隨機抽選、排序其中 4 則進行（Fisher–Yates 洗牌後取前 4 個），確保同一階段不會重複、且每次重玩的事件組合與順序都不同。

### 五項核心指標（0–100，初始 50）

指標旁即時顯示五級評語（危急／警訊／普通／良好／優秀）。每個選項原始的指標增減，會再乘上 **1.8 倍難度倍率**才套用，讓單一選擇的後果更明顯、遊戲更難穩定通關；另外每回合有 +4 的被動基本營收（象徵日常小額收入，不受難度倍率影響），避免「投資信任／民主的合理選擇」必然把財務拖成負值。這兩個效果的加總，就是選完之後徽章顯示、也是實際套用的數字。

| 指標 | 對應簡報概念 |
|---|---|
| 信任 Trust | 相互信任、交換與信任理論、社會連帶 |
| 民主參與 Democracy | 民主控制、Laidlaw 民主健檢原則 |
| 生產者關係 Producer Relations | 生產者困境、反抗通路剝削 |
| 消費者滿意度 Consumer Satisfaction | 消費者困境、糧食主權 |
| 財務 Finance | 共同採購/銷售/信貸的規模經濟 |

任一核心指標（信任、民主、財務）歸零 → 立即觸發失敗結局，並對應簡報「合作社為何失敗」的四大類原因之一：
- **誤解合作**（過度浪漫／過早啟動）
- **支持不足**（成員參與不足／財務支持不足）
- **權力集中**（能力集中／利潤集中／所托非人）
- **治理失敗**（理監事固定化／價值未傳承／缺乏調解機制）

### 四個發展階段

0. **結識夥伴**：正式成立之前的宣傳、招募與磨合——怎麼找到第一批小農與消費者、怎麼談出第一份契作默契、組織的第一筆錢從哪裡來、要不要現在就正式登記。呼應簡報「有共同需求就能合作嗎」的提問（為什麼需要合作社／誰需要／屬於誰／服務誰），也呼應論文中「創辦人墊資」的風險。這個階段的選擇還會累計「路線傾向」（見下方路線分歧）。
1. **共同採購**：降低投入成本，建立初期互信。核心張力：搭便車效應、旁觀者效應、木桶理論（最弱一環）、多態社員（全職／贊助／兼職／休眠）。
2. **共同銷售／品牌**：繞過中間商，直接建立產地到餐桌通路。核心張力：權力集中、治理透明、重大決策是否交付社員表決（Migros 公投事件為原型）、所有權與控制權分離（社員大會淪為追認）。
3. **共同信貸／加工整合**：規模化、垂直整合（Ocean Spray 案例為原型）。核心張力：擴張風險、世代傳承、治理固定化、合作社退化路徑（分光盈餘、拒絕再投資）、偽合作社風險。

每階段的事件池有 5 則、每局隨機抽 4 則進行，另加 1 個「民主健檢」小測驗（4 個選項，改編自 Alexander Laidlaw 的民主原則檢核，固定在該階段最後出現）。

### 路線分歧（結識夥伴階段）

「結識夥伴」的部分選項帶有 `lean` 標記（producer／consumer／hybrid），累計成「生產者傾向」與「消費者傾向」兩個計數。階段結束時依落差判定路線，並改變該階段的小結文字：
- 生產者傾向明顯領先 → **偏生產者導向**路線，小結強調農友共同運銷議價。
- 消費者傾向明顯領先 → **偏消費者導向**路線，小結強調共同購買體系。
- 落差不大 → 維持原本的**生產者＋消費者共治**路線。

路線也會影響最終結局：生產者路線且生產者關係夠高 → **生產者自主型** 🚜；消費者路線且消費者滿意度夠高 → **消費者自主型** 🛍️（優先於下方的一般結局判定）；結局畫面一律會顯示本局最終的路線標籤。

### 成就：所有可能的結局

右上角「🏆 成就」與結局畫面都能打開一份完整目錄，一次列出全部 10 種可能的結局（不論本局有沒有達成），每一則都附上：
- 該結局的描述文字。
- 🔄 **如何走向更好的結局**：只出現在結局畫面本身，針對這次實際達成的結局，說明下次可以怎麼調整選擇。
- 🌍 **現實案例對照**：每種結局都對應一個真實存在的國際合作社案例或研究資料（例如生產者自主型對照 Ocean Spray、消費者自主型對照 Park Slope Food Coop／Bees Coop／La Louve、垂直整合型對照印度 SEWA、深耕社區型對照都柏林社區食物合作社、穩健民主型對照 Migros 公投、勉強維持型對照台灣勞動合作社社員數的官方統計等），讓抽象的指標結局能對照到真實世界的組織型態。

玩家達成過的結局會標記「✓ 已達成」，紀錄存在瀏覽器的 `localStorage`，會跨局累積（但不會跨裝置或跨瀏覽器同步）。

### 結局分歧（走完四個階段後，依最終指標組合與路線判定）

- **生產者自主型** 🚜／**消費者自主型** 🛍️：路線分歧的專屬結局（見上）。
- **深耕社區型** 🌱：生產者關係與消費者滿意度皆高，呼應「社區不是一種業務」的理念。
- **垂直整合型** 🏭：財務與規模皆高，呼應 Ocean Spray 從初級農產品到品牌加工的路徑。
- **穩健民主型** ⚖️：信任與民主參與均衡，規模普通但治理健全。
- **勉強維持型** 🌤️：指標皆未歸零但普遍偏低，鼓勵玩家重玩、嘗試不同選擇。

### 合作社小百科（Glossary）

選擇特定選項後會在回饋卡片中以**可點擊的超連結**列出剛解鎖的條目，點擊會直接開啟百科彈窗並捲動、高亮到該條目。條目共 28 則，分別標註兩個來源：多數條目（案例、理論）改寫自簡報《從產地到餐桌：如何經濟民主》；創辦人墊資風險、合作社資本挑戰、多態社員、所有權與控制權分離、合作社退化路徑、偽合作社風險等 6 則，則改寫自論文《合作的艱難：勞動合作社的比較利益－以勞動者觀點出發》。玩家可隨時在遊戲中打開百科查閱，遊戲結束畫面會列出本局解鎖的條目數。

## 視覺風格

以「食農新日常」為主軸的暖色系（大地綠＋赭橘）風格：
- 標頭有一枚原創的手繪風 SVG 徽章（麥穗＋合掌弧線，象徵農產與合作），favicon 使用 🌾。
- 頁面背景鋪有極淡的麥穗線稿重複紋樣（低對比度，不干擾閱讀）。
- 每個階段有專屬 emoji 圖示（🤝 結識夥伴／🧺 共同採購／🏷️ 共同銷售與品牌／🏭 共同信貸與加工整合），顯示於進度列與該階段的開場／小結卡片。
- 每種結局也有專屬 emoji 圖示，強化情緒收尾。

## 技術架構

- **零建置、純前端**：`index.html` + `css/style.css` + 一般 `<script>` 標籤載入的 `js/*.js`（無 ES module、無 bundler），確保雙擊 `index.html` 或任何靜態伺服器（含 GitHub Pages）都能直接執行，不需要 Node.js 環境。
- `js/content.js`：四階段事件資料（情境、每階段 5 選 4 的事件池、選項、指標增減、回饋文字、解鎖的百科條目 id、路線傾向 `lean`、階段圖示、依路線變化的小結文字）。
- `js/glossary.js`：百科條目資料，各自附帶對應的 `source` 欄位（兩種來源文獻）。
- `js/state.js`：遊戲狀態物件與指標運算（clamp、難度倍率、五級評語、被動財務回饋、事件洗牌與去重、路線判定、失敗判定、結局判定、`ENDING_CATALOG` 結局完整目錄與 `getAllEndings()`）。
- `js/ui.js`：畫面渲染（事件卡＝純文字選項、指標條與動態徽章、百科彈窗、教學彈窗、回饋表單、結局畫面含建議／現實案例對照、成就畫面）。
- `js/main.js`：遊戲流程控制與事件綁定，包含教學彈窗的顯示/略過邏輯、成就紀錄（皆用 `localStorage`）與透過 EmailJS 送出意見回饋的邏輯，程式進入點。
